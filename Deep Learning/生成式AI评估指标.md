# FID (Fréchet Inception Distance)

[[FID指标]]
FID      ↓越低越好   生成图像整体是否接近真实图像分布

FID 会先用预训练 Inception 网络把真实图像和生成图像转成特征，再将两组特征近似看作高斯分布，比较其均值与协方差差异。
- 低 FID：通常意味着生成图片更自然，且整体风格、类别、纹理等统计特性更接近真实集。
- 高 FID：可能表示图像不真实、质量较差，或生成分布偏离真实数据。
局限是 FID 对样本数量、预处理、所用特征提取器很敏感；不同论文若评测设置不同，数值通常不能直接横比。它也未必能发现单张图的具体错误，例如手指异常。


# CLIP-I（CLIP Image Similarity）

CLIP-I     ↑越高越好     生成图像与参考图像的语义/视觉一致性

CLIP-I 通常指生成图像和参考图像分别经 CLIP 图像编码器得到向量后，计算余弦相似度：
  $$\mathrm{CLIP\text{-}I} = \cos(E_{\mathrm{CLIP}}(x_{\mathrm{gen}}), E_{\mathrm{CLIP}}(x_{\mathrm{ref}}))$$
- 高 CLIP-I：表示生成结果在 CLIP 的语义空间里更接近参考图。
- 常见于图像编辑、图像到图像生成、身份保持、风格迁移等任务。
- 它关注“像不像参考图”，不完全等同于像素级一致，也不保证画质高。
注意不要和 CLIP-T 混淆：CLIP-T 评估生成图与文本提示词的一致性；CLIP-I 评估生成图与参考图的一致性。


# Density

Density    ↑越高越好     生成结果在真实数据流形附近的“局部密度”

Density 是 PRDC（Precision、Recall、Density、Coverage）一组分布评估指标中的一个。它看每个生成样本是否落在真实样本特征空间的邻域内，并计数其附近真实样本的数量。
- 高 Density：生成样本通常位于真实数据较密集的区域，局部真实性较强。
- 太高也不必然全是好事：若模型只反复生成少数常见模式，Density 可很高，但多样性可能不足。
它可粗略理解为：“生成的内容是否扎实地落在真实数据常出现的区域中？”


# Coverage

Coverage     ↑越高越好       真实数据中的多样模式有多少被生成模型覆盖

Coverage 看真实样本中有多少比例，其附近能找到生成样本。
- 高 Coverage：说明模型覆盖到了更多真实数据模式，生成多样性和分布覆盖更好。
- 低 Coverage：常提示模式坍塌（mode collapse）——模型只会生成少数类型，遗漏了许多真实类别、姿态、风格或长尾案例。
它可理解为：“真实世界的各种情况，生成模型覆盖得有多全面？”
