# 网络归一化层

网络归一化层是在神经网络内部对激活值或权重进行规范化的模型组件。它们可以改善数值条件、稳定梯度，并降低深层网络对初始化和学习率的敏感性。

> [!note]
> 本文是归一化方法的索引和对比页。训练前对原始输入进行 Min-Max、Z-Score 等缩放，参见 [[数据归一化与标准化]]。

## 统一计算框架

多数激活归一化层包含三步：计算统计量、标准化、可学习仿射变换。

$$
\hat{x}=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}},
\qquad y=\gamma\hat{x}+\beta
$$

- $\epsilon$：防止方差过小时除以 0；
- $\gamma$：可学习的缩放参数；
- $\beta$：可学习的平移参数。

不同方法最关键的差别是：**在哪些维度上计算统计量、是否依赖 mini-batch，以及归一化的是激活值还是权重**。

## 方法导航

| 方法 | 归一化对象/统计范围 | 依赖 batch | 常见场景 |
|---|---|:---:|---|
| [[Batch Normalization]] | 每个通道的 $N,H,W$ | 是 | batch 较大的 CNN |
| [[Layer Normalization]] | 单个样本的特征维度 | 否 | Transformer、RNN |
| [[Instance Normalization]] | 每个样本、每个通道的 $H,W$ | 否 | 风格迁移、图像生成 |
| [[Group Normalization]] | 每个样本、每组通道的 $C/G,H,W$ | 否 | 小 batch 的检测、分割 |
| [[RMSNorm]] | 特征维度的均方根 | 否 | 现代大语言模型 |
| [[Weight Normalization]] | 权重的方向和长度 | 否 | 权重重参数化 |
| [[Spectral Normalization]] | 权重矩阵的最大奇异值 | 否 | GAN、Lipschitz 约束 |
| [[Local Response Normalization]] | 相邻通道的局部响应 | 否 | AlexNet 等早期网络 |

## BN、LN、IN、GN 的维度对比

对于输入张量 `[N, C, H, W]`：

```text
BatchNorm:    跨样本，在每个通道的 N/H/W 维统计
LayerNorm:    每个样本独立，在指定特征维度统计
InstanceNorm: 每个样本、每个通道独立，在 H/W 维统计
GroupNorm:    每个样本独立，通道分组后在 C/G/H/W 维统计
```

## 选择指南

| 任务或条件 | 常见选择 | 主要原因 |
|---|---|---|
| 图像分类 CNN、batch 较大 | [[Batch Normalization]] | 成熟且硬件实现高效 |
| CNN、小 batch | [[Group Normalization]] | 不依赖 batch 统计量 |
| 目标检测、语义分割 | GN 或 SyncBN | 单设备 batch 往往较小 |
| Transformer、RNN | [[Layer Normalization]] | 按样本归一化 |
| 现代大语言模型 | [[RMSNorm]] 或 LN | 与 Transformer 架构适配良好 |
| 风格迁移、部分图像生成 | [[Instance Normalization]] / AdaIN | 处理实例级风格统计量 |
| GAN 判别器稳定性 | [[Spectral Normalization]] | 约束权重谱范数 |

这些只是常见起点，并非绝对规则。最终应结合 batch size、模型架构、训练配方和实际验证结果选择。

## 通用注意事项

- 输入数据标准化和网络归一化层解决的问题不同，通常可以同时使用；
- 包含 BN 的模型必须正确切换 `model.train()` 与 `model.eval()`；
- 使用 [[EMA模型]] 时，应明确如何处理 BN 的 running statistics 等 buffer；
- 使用 [[AMP混合精度]] 时，归一化算子通常由 autocast 选择适合的计算精度；
- 替换归一化层会改变模型行为，加载预训练权重时不能只改层名而忽略状态和维度差异。
